# УСТАНОВКА — «Лето, которого не было» v1.2 (один архив)

Этот архив — **вся игра одним файлом**. Внутри:

```
Leto_kotorogo_ne_bylo/
├── install.py        ← установщик (копирует game/ в ваш проект Ren'Py)
├── УСТАНОВКА.md      ← этот файл
├── README.md         ← описание проекта, changelog, лицензии
├── game/             ← сама игра: сценарий (40 label, 7 концовок), арт, звук, GUI, EN-локализация
├── docs/             ← ГДД-документы, ТЗ по графике/музыке/UI, аудит Ren'Py 8.5.3
└── tools/            ← скрипты проверки и сборки (validate_project.py и др.)
```

Требуется **Ren'Py 8.x** (проверено на 8.5.3): <https://www.renpy.org/latest.html>

---

## Способ 1. Автоматический (рекомендуется)

Ren'Py-проект создаётся один раз через Launcher (**Create New Project**, любое имя,
например `leto`), затем:

```bash
# распакуйте архив куда угодно и из папки с install.py выполните:
python install.py "C:/Users/ВАС/renpy-8.5.3-sdk/leto"      # Windows
python3 install.py ~/renpy-8.5.3-sdk/leto                  # macOS / Linux
```

Путь — это папка **проекта** (та, внутри которой лежит `game/`), а не папка SDK.

Что делает скрипт:
1. переименовывает шаблонный `game/script.rpy` → `_template_script.rpy.bak`
   (иначе Ren'Py стартует из шаблона и показывает Эйлин);
2. удаляет шаблонные авто-картинки `bg *` / `eileen *`, конфликтующие с нашим `images.rpy`;
3. копирует наши `.rpy`, `images/`, `audio/`, `gui/`, `tl/english/`;
4. прописывает название и версию в `options.rpy`;
5. выставляет палитру ГДД в `gui.rpy`.

После этого в Launcher: **Launch Project**. Если Launcher был открыт — закройте проект
и откройте заново (Ren'Py кэширует список файлов).

## Способ 2. Руками (3 действия)

1. В папке вашего проекта удалите/переименуйте `game/script.rpy`.
2. Удалите из `game/images/` файлы, начинающиеся на `bg ` и `eileen`.
3. Скопируйте **содержимое** папки `game/` из архива в `game/` проекта с заменой.

## Способ 3. Чистый проект

Скопируйте всю папку архива в SDK и переименуйте её в `leto_kotorogo_ne_bylo`,
затем в `game/` не должно остаться шаблонного `script.rpy` (в архиве его нет —
точка входа объявлена в нашем `script.rpy`). Проект подхватится Launcher'ом как обычный.

## Что изменилось в v1.2 (почему архив теперь один и в 4 раза меньше)

Содержимое игры то же, что в v1.1 (те же фоны, спрайты, CG, музыка, сюжет),
но ассеты пережаты в форматы, которые Ren'Py 8 поддерживает официально:

| что | было (v1.1) | стало (v1.2) |
|---|---|---|
| фоны и CG, 33 шт. | JPEG q90, ~16 МБ | **WebP q76**, ~8 МБ (1920×1080) |
| спрайты, 18 шт. | PNG, ~10 МБ | **WebP q86** с альфой, ~1.3 МБ |
| меню-арт, карточки | PNG/JPEG, ~4.7 МБ | **WebP q85**, ~0.8 МБ |
| музыка, 9 петель | Ogg Vorbis ~120 кбит/с, 11.7 МБ | **Ogg/Opus**, ~5 МБ |
| SFX и амбиенты, 18 | Ogg Vorbis, 4 МБ | **Ogg/Opus mono**, ~0.5 МБ |
| шрифты PT | 8 файлов, 3 МБ | 4 используемых, сабсет, ~0.5 МБ |

* WebP и Opus — в официальных списках поддерживаемых форматов Ren'Py
  (`doc/html/displayables.html`: «AVIF WEBP PNG JPG»; `doc/html/audio.html`: «Opus, Ogg Vorbis, MP3…»).
* Музыкальные петли пережаты без потери бесшовности: после кодирования проверяются
  длительность (совпадает до миллисекунды) и RMS первых/последних 20 мс.
* Все ссылки в `.rpy` переписаны автоматически, сборка не проходит, если хотя бы
  одна ссылка битая (`tools/validate_project.py`).

Проверить архив без запуска игры:

```bash
python3 tools/validate_project.py game
```

## Если что-то не так

| симптом | причина / лечение |
|---|---|
| Запустилась Эйлин, «Вы создали новую игру Ren'Py» | остался шаблонный `game/script.rpy` → запустите `install.py` или удалите его вручную |
| Ошибка `duplicate label start` | то же самое: два `label start` (наш и шаблонный) |
| Чёрные квадраты вместо фонов | не скопировалась папка `game/images/` |
| Нет музыки | не скопировалась `game/audio/`; либо очень старый Ren'Py 7.x — нужен 8.x |
| Всё огромное / вылезает за экран | в `gui.rpy` нет `config.screen_width/height` — берите `gui.rpy` из архива целиком |
| При выходе краш `yesno_prompt` | не скопирован наш `screens.rpy` |

Полный разбор 9 классов ошибок и матрица окружения — `docs/11_аудит_RenPy_8.5.3.md`.

## Быстрая проверка после установки

- Главное меню: арт с логотипом, кнопки «Начать / Продолжить / Настройки…».
- `Начать` → пролог: комната Артёма (настоящий фон), музыка `main_theme`.
- У ворот — CG `cg_lena_gate` и полу-ростовой спрайт Лены.
- Консоль (Shift+O): после выбора «Осмотреть билет внимательно» → `truth_points == 1`.
- Preferences → Language → English: локализованы все 1450 строк.
- 7 концовок; секретная открывается только после `persistent.true_seen`.
