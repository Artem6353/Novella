## 1. Диалоговое окно (dialogue box)

**Тип:** UI-панель
**Описание:** полупрозрачная панель «молочная бумага» в нижней трети экрана, тонкая рамка, слева — место под имя персонажа (янтарная подложка), лёгкая зернистость бумаги. Высота ~200 px при 1080p.
**Промт:**
```
game dialogue box UI element, horizontal semi-transparent cream paper panel, subtle grain texture,
thin dark graphite border 2px, small name tag plate on the left with amber background,
rounded corners 6px, soft inner shadow for text readability, empty of text,
soft semi-transparent paper panel, faded cream paper texture, minimal decoration --ar 3:1 --style raw --v 6
```
**Требования:** контраст текста к подложке ≥ 4.5:1; подложка затемняет фон под собой на 55–70 %;
базовый размер текста 30 px; возможность увеличить до 36 px в настройках.

## 2. Кнопка выбора (choice button)

**Тип:** UI-элемент (3 состояния: default / hover / disabled)
**Описание:** удлинённая «бумажная» плашка с тонкой рамкой; в hover — янтарная рамка и лёгкое поднятие; активный выбор отличается **не только цветом, но и рамкой + маркером слева** (требование доступности: цвет не единственный канал информации).
**Промт:**
```
game menu button UI element, horizontal cream paper strip with thin graphite border,
small amber diamond marker on the left side, empty of text, three states sheet:
normal, hovered with amber glowing border, disabled greyed out, minimal flat design,
soft semi-transparent paper panel, faded cream paper texture --ar 3:1 --style raw --v 6
```
**Требования:** высота 64–72 px; отступ между кнопками 12 px; поддержка клавиатуры (стрелки + Enter);
фокус виден без мыши (рамка 3 px `#ffb703`).

## 3. Главное меню (main menu background + layout)

**Тип:** фон + компоновка
**Описание:** лагерь на закате, площадь и сосны; название игры крупным шрифтом с засечками в верхней трети; вертикальный список пунктов слева или по центру; кнопки — «бумажные» плашки.
**Промт (фон):**
```
main menu background art, empty camp square at sunset viewed from a low angle, flagpole and old wooden stage,
pine trees silhouettes, warm amber sky with deep blue shadows, soft haze, plenty of empty space
in the center for UI text, cinematic composition, faded cream vignette at the edges --ar 16:9 --style raw --v 6
```
**Пункты:** Новая игра / Продолжить / Загрузить / Настройки / Галерея / Выход.
**Требования:** название не должно перекрывать горизонт; при 16:10 и 4:3 — безопасные поля 80 px.

## 4. Экран галереи (gallery)

**Тип:** UI-экран
**Описание:** сетка 4×2 миниатюр CG на «бумажном» фоне; закрытые CG — тёмная плашка с силуэтом замка/билета; внизу — страницы и подпись концовки.
**Промт:**
```
game gallery screen UI layout, grid of eight empty thumbnail frames on faded cream paper background,
thin graphite borders, locked slots shown as dark placeholders with a small ticket icon,
page arrows at the bottom, warm amber highlights, minimal clean interface, empty of text --ar 16:9 --style raw --v 6
```
**Требования:** превью открывается только после просмотра (persistent.gallery_unlocked);
подпись каждой CG видна при наведении; клавиатурная навигация по сетке.

## 5. Экран настроек (preferences)

**Тип:** UI-экран
**Описание:** две колонки слайдеров (текст/музыка/звуки/голос), переключатели (авто-режим, пропуск, скорость текста, анимация текста), выбор языка (RU/EN), выбор разрешения и полноэкранного режима.
**Промт:**
```
game settings screen UI layout, two columns of empty horizontal sliders with amber handles,
toggle switches in pine green, dropdown selectors, faded cream paper panels with thin borders,
clean minimal interface, empty of text, warm lighting --ar 16:9 --style raw --v 6
```
**Требования (раздел 29 ГДД):** скорость появления текста; автопродвижение; пропуск прочитанного/всего;
история диалогов; отключение анимации текста; размер текста 28–36 px.

---

## 6. Экран сохранений (save/load)

**Тип:** UI-экран
**Описание:** сетка слотов 4×3, каждый слот — миниатюра фона + номер + дата/время + название сцены; пустые слоты — «чистый лист»; панель подтверждения удаления.
**Промт:**
```
game save load screen UI layout, grid of twelve empty save slot cards on cream paper background,
each card with a small blank screenshot area and thin graphite frame, one card highlighted with amber border,
minimal clean interface, empty of text --ar 16:9 --style raw --v 6
```
**Требования:** автосохранение в начале каждого дня; быстрые слоты (F5/Shift+F5);
подтверждение перед перезаписью и удалением.

## 8. ШРИФТЫ И GUI-НАСТРОЙКИ REN'PY

Файлы `gui.rpy` и `screens.rpy` берутся из шаблона Ren'Py 8; правятся только значения ниже.

```python
## --- gui.rpy: цвета (раздел 28 ГДД) ---
define gui.accent_color       = '#ffb703'   # закатный янтарь
define gui.idle_color         = '#1f1b16'   # тёмный графит
define gui.idle_small_color   = '#5b534a'
define gui.hover_color        = '#c8a2ff'   # сумеречный фиолетовый (ховер)
define gui.selected_color     = '#2d6a4f'   # сосновый зелёный
define gui.insensitive_color  = '#8a8378'
define gui.text_color         = '#f6f1e7'   # молочная бумага (текст на тёмной подложке)
define gui.interface_text_color = '#1f1b16'

## --- gui.rpy: размеры и шрифты ---
define gui.text_size          = 30          # базовый нарратив (28–32 px по ГДД)
define gui.interface_text_size = 28
define gui.name_text_size     = 32
define gui.label_text_size    = 34
define gui.notify_text_size   = 26

define gui.text_font          = "gui/fonts/PTSerif-Regular.ttf"
define gui.name_font          = "gui/fonts/NotoSerif-Bold.ttf"
define gui.interface_text_font = "gui/fonts/PTSans-Regular.ttf"

## --- gui.rpy: диалоговое окно ---
define gui.textbox_height     = 205
define gui.textbox_yalign     = 1.0
define gui.name_xpos          = 30
define gui.name_ypos          = -8
define gui.dialogue_xpos      = 40
define gui.dialogue_ypos      = 60
define gui.dialogue_width     = 1840

## --- gui.rpy: кнопки выбора ---
define gui.choice_button_width = 1200
define gui.choice_button_height = 70
define gui.choice_button_tile  = False
define gui.choice_button_text_font = gui.interface_text_font
define gui.choice_button_text_size = 30
```

**Файлы шрифтов** (положить в `game/gui/fonts/`, все с кириллицей):
- `PTSerif-Regular.ttf`, `PTSerif-Italic.ttf` — нарратив;
- `PTSans-Regular.ttf`, `PTSans-Bold.ttf` — интерфейс;
- `NotoSerif-Bold.ttf` — заголовки и имена;
- `NotoSans-Regular.ttf` — запасной.

**Подложка диалога** (если нет арт-панели из п.1):
```python
## screens.rpy → screen say
add Frame("gui/textbox.png", gui.frame_borders)   # или временно:
add Solid("#1f1b16a0", xysize=(1920, 205), ypos=875)
```

**Цвета имён персонажей** уже заданы в `characters.rpy`: Артём `#1f1b16`, Лена `#c8a2ff`,
Вера `#ffd166`, Зоя `#8ecae6` — на тёмной подложке все четыре дают контраст ≥ 4.5:1.
