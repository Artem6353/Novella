## 0. ОБЩИЙ СТИЛЬ (добавлять в конец каждого промта)

**BASE_STYLE (фоны и CG):**
```
semi-realistic anime style, painterly texture, nostalgic mood, warm amber lighting,
deep blue shadows, 1990s post-soviet aesthetic, cinematic composition, soft film grain,
watercolor sky, hand-painted background
```

**BASE_STYLE_NOPEOPLE (только фоны):**
```
+ empty scene, no people, no characters
```

**NEGATIVE (единый для всех ассетов):**
```
text, watermark, logo, signature, ui elements, extra fingers, deformed hands, modern cars,
smartphone, plastic, neon lights, cyberpunk, sci-fi, horror, blood, gore, scary, nsfw,
lowres, blurry, jpeg artifacts, oversaturated, 3d render, photorealistic photo
```

**ПАРАМЕТРЫ:**
- фоны и CG: `--ar 16:9 --style raw --v 6`
- спрайты: `--ar 2:3 --style raw --v 6 --niji 6` (для SD: `--ar 2:3`, шаг 30, CFG 6–7)

**ПАЛИТРА (раздел 28 ГДД):** молочная бумага `#f6f1e7`, графит `#1f1b16`, янтарь `#ffb703`,
сосновый `#2d6a4f`, сумеречный фиолетовый `#5e548e`, приглушённый красный `#9d4c4c`.

## 7. ЧЕК-ЛИСТ ПРИЁМКИ АССЕТА

1. ID файла совпадает с именем в `images.rpy` (например `bg_gate.webp`).
2. Разрешение и формат соответствуют типу (1920×1080 / спрайт 1000–1400 px по высоте).
3. Нет читаемого текста на табличках и плакатах (текст добавляется в движке).
4. Спрайты: одинаковый масштаб, прозрачный фон, единый источник света.
5. Палитра укладывается в шесть цветов ГДД (раздел 28).
6. Нет элементов хоррора, крови, современности (телефоны, пластиковые окна, LED).
7. Фон не спорит с текстом: нижняя треть темнее (контраст ≥ 4.5:1 под диалоговым окном).
8. Каждый ассет проверен в движке на реальной сцене, а не в папке.
