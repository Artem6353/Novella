## ФАЗА 1. ТЕСТИРОВАНИЕ ДЕМО (1 неделя)

### 1.1 Автотесты (своими силами)
1. **Прогон всех переходов демо:** `start → p01_room → p02_bus → d00_gate → d00_square → d1_morning → d1_canteen → d1_library → d1_evening_choice → (3 варианта) → d1_night_walk → d2_morning → крючок`.
2. **Проверка флагов** (Ren'Py Launcher → Developer → Console, или `Shift+Alt+D`): после каждого выбора сверить `truth_points`, `lena_love/vera_love/zoya_love`, `memory_fragments`, `drawing_found`, `has_ticket`.
3. **Rollback-тест по ГДД (раздел 30, п.4–5):** дойти до выбора → выбрать → получить флаг → откатиться → выбрать другое → убедиться, что старые флаги не остались и `memory_fragments` не превысил максимум.
4. **Тест ветвления:** три прогона демо — с Верой, с Зоей, с Леной; сверить, что различается текст, а не только счётчики.
5. **Технические проверки (раздел 31, п.6):** кириллица, переносы строк, история диалогов, skip, автосохранение, загрузка, музыка без щелчка, SFX не перекрывают текст.

### 1.2 Внешнее тестирование (5–8 человек)
**Кого звать:** 3 человека, которые любят сюжетные новеллы; 2 человека, которые новеллы не играли; 1 человек 16–18 лет (целевая аудитория); 1 человек с опытом локализации/редактуры (ловить опечатки).

**Что просить сделать:** пройти демо молча, не спрашивая подсказок, и ответить на 6 вопросов:
1. В какой момент тебе стало интересно? В какой — скучно?
2. Что, по-твоему, здесь происходит? (без спойлеров из ГДД)
3. Кого из трёх девушек ты запомнил и почему?
4. Заметил ли ты хотя бы одну «странность»? Какую?
5. Понятно ли, что твой выбор что-то меняет?
6. Хотел бы ты продолжить? Что тебе пообещать в полной версии?

**Метрики, которые снимаем сами:** время прохождения (норма 30–45 мин), количество сохранений/загрузок, сколько раз игрок открывал историю диалогов, где выходил из игры.

**Красные флаги (чиним до публикации):**
- игрок не понял, что лагерь повторяется;
- игрок не запомнил ни одной героини по имени;
- текст читается с трудом (контраст/размер/переносы);
- игрок не понял, зачем Артём приехал;
- «странности» воспринимаются как баги, а не как приём.

## ФАЗА 2. ПУБЛИКАЦИЯ ДЕМО (2–3 дня)

### 2.1 Подготовка страницы
1. Завести/обновить страницу на itch.io, текст — из `docs/08_itch_io.md`.
2. Загрузить 5–8 скриншотов: ворота с Леной, площадь, столовая, библиотека, радиоузел, река (минимум 2 с реальным артом, не плейсхолдеры).
3. Обложка (630×500) и баннер (1920×1080) — `cg_lena_gate` или `bg_gate` с названием и тэглайном.
4. Короткий трейлер 30–45 сек (опционально, но сильно поднимает конверсию): 5 статичных кадров + музыка Main Theme + 3 фразы Лены + дата «демо доступно».
5. Настроить: `Kind of project: Games`, теги из `docs/08`, `This game will not contain AI-generated content` — **заполнить честно** (если арт/музыка сгенерированы, указать это в разделе «AI disclosure»; на itch.io это отдельное обязательное поле).
6. Поставить цену: демо — бесплатно или «name your own price».
7. Включить комментарии и форму фидбека (Google Forms: 5 вопросов, 1 минута).
8. Загрузить билды: Windows, Linux, macOS, Web (HTML5). Для Web — проверить, что он играет в браузере Chrome/Firefox и не требует плагинов.

### 2.2 Чек-лист перед нажатием «Publish»
- [ ] Все четыре билда скачаны и запущены на чистой машине.
- [ ] В Web-версии нет ошибок в консоли браузера.
- [ ] Размер демо ≤ 300 МБ (Web ≤ 150 МБ), иначе загрузка отпугнёт.
- [ ] В игре нет отладочного текста, placeholder-заглушек в демо-зоне, русских опечаток (прогнать текст через спелл-чек).
- [ ] Указаны content warnings.
- [ ] Указано, что это демо, и написано, что будет в полной версии.
- [ ] Есть хотя бы один способ связи (почта/Discord/форма).

## ФАЗА 3. СБОР ФИДБЕКА (2–3 недели после релиза демо)

**Что собираем:**
1. Комментарии на itch.io (читать все, отвечать на каждый).
2. Ответы формы фидбека (те же 6 вопросов + «что сломалось»).
3. Баги: отдельная таблица — `id / сцена / что случилось / воспроизводится ли / приоритет`.
4. Статистика: сколько скачиваний, сколько прошли до конца демо (если включён счётчик), средний рейтинг.

**Как приоритизируем:**
| Приоритет | Что это | Срок |
|---|---|---|
| P0 | Игра не запускается, мёртвая ветка, сломанный флаг, нечитаемый текст | 48 часов |
| P1 | Непонятна мотивация, «странность» выглядит как баг, звук мешает чтению | до патча демо |
| P2 | Пожелания по сюжету, просьбы добавить маршрут/CG | учитываем в полной версии |
| P3 | Вкусовщина («хочу озвучку», «хочу хоррор») | фиксируем и вежливо отказываем |

**Патч демо (v0.9.1):** только P0 и P1. Обновить билды, написать в devlog «что поправили» — это возвращает часть игроков.

## ФАЗА 4. ПОЛНАЯ ВЕРСИЯ (3–5 месяцев)

### 4.1 Порядок работ
1. **Сценарий уже готов** (все 25 сюжетных сцен + 7 концовок в `game/scenes/*.rpy`) — остаётся редактура по фидбеку демо.
2. **Арт (критический путь):** P1-фоны (8) → спрайты 3×6 → CG (10). Оценить: 1 фон = 4–8 ч, 1 спрайт = 2–3 ч, 1 CG = 8–16 ч. Итого ≈ 400–600 часов — планировать подрядчиков заранее.
3. **Музыка:** 9 треков + 18 SFX (см. `docs/05`, `docs/06`).
4. **UI:** финальные панели по `docs/07`, экран галереи и «фрагменты памяти».
5. **Локализация:** вынести весь текст в translation-блоки Ren'Py, собрать EN-версию.
6. **QA полного цикла:** 7 прохождений — по одному на каждую концовку (см. маршруты ниже).

### 4.2 Маршруты для обязательного QA-прогона
| Прогон | Цель | Ожидаемая концовка |
|---|---|---|
| 1 | Максимум с Леной + все фрагменты + правда | `ending_true` |
| 2 | То же, но второй заход (`persistent.true_seen`) + `father_clue` + «унести память» | `ending_secret` |
| 3 | Лена, `lena_love >= 6`, «остаться» | `ending_lena_stay` |
| 4 | Вера, починено радио, `vera_love >= 8` | `ending_vera_voice` |
| 5 | Зоя, рисунок найден и дорисован, `zoya_love >= 8` | `ending_zoya_painting` |
| 6 | Минимум отношений, мало правды | `ending_farewell` |
| 7 | «Остаться одному» в `D3_ALONE` | `ending_forgotten` |

**Отдельные проверки:** при `escape_flag` меню финального выбора не появляется; `father_clue` выдаётся только в `D2_NIGHT_FOREST`; секретная концовка недоступна без `persistent.true_seen`; `escape_flag` сбрасывается в `d3_route_select`.

### 4.3 Релиз полной версии
1. Закрытое бета-тестирование (10–20 человек из числа тех, кто оставлял фидбэк на демо) — 2 недели.
2. Финальный билд: Win/macOS/Linux/Web + (опционально) Android-порт.
3. Цена: 4,99–7,99 $ или «name your own price» с минимумом.
4. Пресс-кит: обложка, 10 скриншотов, 3 GIF, трейлер 60–90 сек, текст из `docs/08`, контакты.
5. Разослать пресс-кит: VN-блоги, itch.io-фичи (подать заявку на featuring за 3 недели), русскоязычные паблики, стримеры.
6. Релизный devlog + пост-релизный патч в течение недели.

### 4.4 После релиза
- Неделя 1: отвечать на все комментарии, собрать баги, выпустить hotfix.
- Неделя 2–4: опрос «какая концовка ваша любимая» → данные для решения о сиквеле/фан-контенте.
- Месяц 2: английская локализация (если демо показало интерес не-русской аудитории).
- Месяц 3: артбук/саундтрек как отдельная страница (дополнительный доход при нулевых новых затратах).

## ФАЗА 5. РИСКИ И ЧТО ДЕЛАТЬ

| Риск | Вероятность | Митигция |
|---|---|---|
| Арт не успевается | высокая | Держать Solid-плейсхолдеры рабочими; релизить по частям (сначала маршруты Лены и Веры) |
| Игрок не понимает петлю | средняя | Усилить 3 «странности» в демо, добавить панель «Фрагменты памяти» как явный фидбэк |
| Секретную концовку не найдут | высокая | После `ending_true` показывать подсказку: «В коробке осталось что-то ещё» (`persistent.secret_hint_seen`) |
| Web-сборка тяжёлая | средняя | Сжимать фоны в WebP, музыку в OGG 96–128 kbps, CG — до 1600 px |
| Выгорание соло-разработчика | высокая | Фиксированный объём демо, работа по фазам, публичные дедлайны в devlog |
