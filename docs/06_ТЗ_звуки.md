# ЭТАП 6. ТЗ ДЛЯ ЗВУКОВ (SFX)
## «Лето, которого не было» — 18 эффектов

> **СТАТУС: ВСЕ 18 ЭФФЕКТОВ СИНТЕЗИРОВАНЫ И ОТРЕДЕРЕНЫ** как звуковой дизайн
> (`tools/compose_sfx.py`): шумовые спектры, резонансы, огибающие, бесшовные лупы.
> Файлы: `game/audio/sfx/*.ogg` и `web_demo/audio/sfx/*.ogg`.
> Строки `play sound …` в сценах активированы; луп-эффекты помечены `loop`.
>
> Формат: **OGG (или WAV), 44.1 kHz, стерео/моно**, пик ≤ −3 dB.
> Пути и имена — как в `game/audio.rpy` (`audio/gate_creak.ogg`, `audio/glitch.ogg`, …).
> Все SFX должны быть «сухими» по характеру: без музыкальности, без реверберационных хвостов длиннее 1.2 сек.

**Общий промт-суффикс для генераторов звука (ElevenLabs SFX / AudioGen / freesound-поиск):**
```
field recording style, natural, no music, no voice, clean, 1990s analog warmth
```

## ПРАВИЛА СВЕДЕНИЯ

1. **SFX тише музыки** на 6–10 dB: звук не должен перекрывать чтение (тест-план, раздел 31).
2. **Loop-эффекты** (`wind`, `crickets`, `river`, `bus_engine`, `rain`, `fire_crackle`, `broadcast`) — бесшовные, стык не слышен.
3. **Одноразовые эффекты** (`glitch`, `bell`, `glass`, `gate_creak`, `door`) — с коротким fade-out, без обрезанного хвоста.
4. **`glitch`** не должен быть резким: это сбой памяти, а не скример (рейтинг 16+, без хоррора).
5. Все звуки нормализованы к одному пику (−3 dB) — иначе «колокол» будет громче «автобуса» в три раза.
6. В движке: `play sound X` для одноразовых, `play sound X loop` для фоновых; `stop sound fadeout 1.5` при смене локации.
