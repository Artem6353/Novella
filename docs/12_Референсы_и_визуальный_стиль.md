# ЭТАП 12. Анализ референсных новелл и применённый визуальный стиль
## «Лето, которого не было» — v1.1

Документ составлен после разборa скриншотов и устройства референсов:
**«Бесконечное лето» / Everlasting Summer** (Soviet Games), **Doki Doki Literature Club** (Team Salvato),
а также общей практики коммерческих VN на Ren'Py. Цель — привести игру к «нормальному» виду новеллы,
как просил заказчик.

---

## 1. Что видно в референсах (разбор скриншотов)

### Everlasting Summer
1. **Фон — полнокадровый 16:9**, яркая живописная прорисовка (небо, детали лагеря), без рамок,
   без размытых полей, без леттербоксов. Кадр читается целиком от края до края.
2. **Спрайт персонажа** — по пояс/по бедро, занимает ~90–100 % высоты экрана, стоит на нижней
   кромке, чистые прозрачные края, крупное читаемое лицо.
3. **Диалоговое окно** — широкая тёмная полупрозрачная плашка внизу с тонкой светлой каймой;
   имя персонажа — отдельным «язычком»/плашкой над текстом; текст белый, крупный.
4. **Выборы** — полупрозрачные тёмные плашки слева, а не по центру: не перекрывают персонажа.
5. **Портрет говорящего** — маленькая иконка в углу диалогового окна (опционально).
6. **Меню** — арт лагеря во весь экран, логотип игры сверху, кнопки слева вертикальным списком.

### Doki Doki Literature Club
1. **Диалоговое окно** — скруглённая плашка с текстурой, имя — вкладкой НАД окном;
   быстрое меню (History/Skip/Auto/Save/Load/Settings) встроено полосой ВНУТРИ низа окна,
   мелким кеглем, не отвлекает.
2. **Спрайты** — крупные, по пояс вблизи, эмоциональные лица занимают центр кадра.
3. **Фон** — полнокадровый, перспектива комнаты симметричная, световые акценты.
4. Карточки глав/сцен — стилизованные полноэкранные заставки, а не «чёрный экран с текстом».

### Общие правила жанра (сводка)
- Никаких размытых боковых полей и «квадрат посередине»: только full-bleed 16:9.
- Диалог: 1 окно внизу (~20–25 % высоты), имя выделено плашкой/вкладкой, кегль текста 28–32 px при 1080p.
- Быстрое меню — мелкое, полупрозрачное, внутри окна или у его кромки.
- Выборы — слева или справа колонкой, полупрозрачные, с hover-подсветкой.
- Главы открываются полноэкранной стилизованной карточкой (фон-градиент/арт + типографика).
- Меню: арт + логотип + вертикальный список кнопок; шрифты с характером, а не системные.

## 2. Что было у нас и что изменено в v1.1

| Проблема (до) | Решение (v1.1) |
|---|---|
| Фоны и CG = «квадрат + размытые боковые поля» | Все 20 фонов и 13 CG перерисованы в бесшовные полнокадровые 16:9 (image-to-image с сохранением композиции/палитры), проверка резкости по краям — полос не осталось |
| Карточки глав = чёрный экран с репликой в диалоговом окне | Новый экран `chapter_card`: полноэкранный градиентный фон с виньеткой и зерном, серифная типографика, янтарные линейки (как глав-заставки в ES/DDLC) |
| Диалоговое окно = глухая полоса во всю ширину, имя просто строкой | Окно 1560 px со скруглённой полупрозрачной плашкой и тёплой каймой (Frame 9-slice), имя — янтарной вкладкой над текстом (паттерн DDLC/ES) |
| Быстрое меню = текст в углу поверх сцены | Встроено полосой в низ диалогового окна, кегль 15, полупрозрачное (паттерн DDLC) |
| Выборы = светлые кнопки по центру поверх персонажа | Колонка слева, тёмные полупрозрачные плашки с янтарным hover (паттерн ES) |
| Меню = арт с размытыми полями, заголовок текстом по центру, кнопки по центру | Новый арт ворот лагеря (full-bleed), логотип PT Serif BoldItalic с тенью и янтарной линией, кнопки слева вертикальным списком на полупрозрачных плашках |
| Системный шрифт DejaVuSans | PT Sans (текст/интерфейс) + PT Serif (логотип/карточки) — OFL-шрифты с кириллицей, «книжный» характер |
| Экран меню игр (save/load) — контрастный арт | game_menu.png = затемнённый и размытый ключевой арт (читаемость панелей) |

## 3. Контроль качества арта
- Автотест резкости: `tools/validate_project.py` + скрипт сравнения резкости центр/края —
  у всех 33 кадров боковые зоны больше не размыты.
- Сравнение средней палитры со старой версией (release-пакет v1.0): отклонения ≤ 0.13 по яркости
  (осознанная осветлённость/затемнённость ремaster-кадров),hue сохранён.
- Спрайты: прозрачность (альфа-канал), полу-рост, zoom 1.18 → ~90 % высоты экрана (норма ES/DDLC).

- Практика Ren'Py-новелл: полнокадровые фоны, карточки глав, вертикальные меню.
