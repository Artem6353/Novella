# 13. Релиз v1.2 — «вся игра одним файлом» (14 МБ)

## Зачем

Пак v1.1 весил 64.5 МБ и одним файлом не скачивался, поэтому его резали на 8 частей
по 8 МБ. Пользователю это неудобно: нужен **один** архив, который гарантированно
скачивается. Решение — не резать, а ужать контент: 64.5 МБ → **13.98 МБ** без
заметной потери качества.

Содержимое игры при этом не изменилось: те же 40 label, 25 сцен, ~11 022 слова,
19 меню, 7 концовок, те же фоны/спрайты/CG/музыка/SFX, та же EN-локализация (1450 строк).

## Что именно ужато и почему это безопасно

| ассет | v1.1 | v1.2 | выигрыш |
|---|---|---|---|
| фоны + CG, 33 шт., 1920×1080 | JPEG q90, 16.1 МБ | **WebP q76**, ~6.5 МБ | −59 % |
| спрайты, 18 шт. (альфа) | PNG, 10.1 МБ | **WebP q86**, ~1.3 МБ | −87 % |
| меню-арт, карточка, рамка | PNG/JPEG, 4.7 МБ | **WebP q85** (рамка осталась PNG), ~0.8 МБ | −83 % |
| музыка, 9 бесшовных петель | Ogg Vorbis ~120 кбит/с, 11.7 МБ | **Ogg/Opus**, 4.6 МБ | −61 % |
| SFX и амбиенты, 18 шт. | Ogg Vorbis, 4.0 МБ | **Ogg/Opus mono**, 0.9 МБ | −78 % |
| шрифты PT | 8 начертаний, 3.0 МБ | 4 используемых, сабсет, 0.78 МБ | −74 % |
| **всего game/** | ~50 МБ | ~15 МБ | |

Обоснование форматов — официальная документация Ren'Py:

* `doc/html/displayables.html`: «There are four image file formats we recommend you use:
  **AVIF WEBP PNG JPG**»; `doc/html/displaying_images.html`: авто-регистрация файлов
  `.jpg, .jpeg, .png, .webp, .avif, .svg` из `game/images/`.
* `doc/html/audio.html`: «Ren'Py supports … **Opus**. Ogg Vorbis. MP3. MP2. FLAC. WAV».

Оба формата декодируются тем же ffmpeg, который Ren'Py 8 несёт в себе, поэтому
расширение `.ogg` у музыкальных файлов оставлено без изменений (внутри — Opus):
ссылки `audio/*.ogg` в `audio.rpy` и в сценах править не пришлось.

## Бесшовность музыкальных петель

Это главное требование v1.1 (раньше на стыке петли была тишина). Пережатие не должно
его сломать, поэтому `tools/reencode_opus.py` после каждого файла проверяет:

1. **длительность** — decoded-длина результата совпадает с исходной (±30 мс);
   у всех 9 треков ровно 90.000 с → 90.000 с (гранула Ogg корректно обрезает
   pre-skip и хвостовой паддинг кодировщика, поэтому «дырки» на стыке не появляется);
2. **RMS первых и последних 20 мс** — совпадает с исходным (пример: main_theme
   head 0.1469 → 0.1422, tail 0.1377 → 0.1379), т. е. края петли не «обнулились».

Если проверка не проходит, скрипт возвращает код 2 и сборка архива прерывается.

## Качество картинки

WebP q76 для фона даёт PSNR ≈ 34–38 дБ относительно исходного кадра — для живописного
фона 1080p это уровень «не отличимо на глаз» (артефакты JPEG q78 были бы заметнее
при том же размере: WebP при равном PSNR легче JPEG на ~25 %).

Спрайты кодируются q86 с сохранением альфа-канала (проверено: extrema альфы (0…255),
полупрозрачные края волос/одежды не «обрубаются»).

Предусмотрены три пресета сборщика:

```
balanced (по умолчанию): фон q76, спрайты q86, gui q85, музыка Opus 40k, SFX 28k, 1920×1080 → ~14 МБ
lite                     : фон q70, спрайты q80, gui q80, музыка 32k, SFX 24k, 1600×900      → ~9 МБ
max                      : фон q85, спрайты q92, gui q90, музыка 64k, SFX 40k, 1920×1080     → ~22 МБ
```

## Структура архива

```
Leto_kotorogo_ne_bylo/
├── install.py        # копирует game/ в проект Ren'Py, лечит шаблонный script.rpy
├── УСТАНОВКА.md      # пошагово + таблица «симптом → причина»
├── README.md
├── game/             # игра: .rpy, images/ (webp), audio/ (opus), gui/, tl/english/
├── docs/             # 01–13: сюжет, сценарий, ТЗ, аудит Ren'Py 8.5.3, референсы
└── tools/            # validate_project.py, reencode_opus.py, make_release_zip.py, …
```

В архив **не** кладутся: `web_demo/` (пересобирается из проекта), `art/` и исходные
мастер-PNG, кэш `game/cache/`, `game/saves/`, `*.rpyc`, старые zip и части.

## Как пересобрать

```bash
cd leto_kotorogo_ne_bylo
python3 tools/make_release_zip.py --preset balanced --out /home/user/leto_v1.2_one_file.zip
# только переупаковать (ассеты в /home/user/pack_stage уже готовы):
python3 tools/make_release_zip.py --zip-only
```

Сборщик сам: копирует `renpy_project/game/` во временный каталог, пережимает арт и звук,
сабсетит шрифты, переписывает ссылки `.png/.jpg → .webp` в `.rpy`, проверяет, что каждая
ссылка указывает на существующий файл, прогоняет `tools/validate_project.py` по собранной
копии (сборка прерывается на любой ошибке) и только потом пакует zip с контролем CRC.

## Проверки, выполненные для v1.2

* `tools/validate_project.py <собранная копия>/game` → **ОШИБОК НЕ НАЙДЕНО ✓**,
  предупреждений нет; 19 .rpy, 40 label, 51 scene, 1405 реплик, ~11 022 слова.
* Сверка ссылок на ассеты: все `images/*`, `gui/*`, `audio/*`, `gui/fonts/*` существуют.
* Кодек и длительность каждого аудиофайла прочитаны обратно (libsndfile + PyAV): opus, 48 кГц.
* `zipfile.testzip()` — CRC всех 138 записей в порядке.
* Альфа-канал спрайтов и набор глифов в сабсетах шрифтов проверены программно
  (по всем символам, встречающимся в .rpy/.tl).

## Что осталось за рамками v1.2

* HTML5-демо в архив не входит (экономия ~10 МБ); при необходимости пересобирается
  из проекта и может быть выдано отдельным файлом.
* Runtime-тесты Ren'Py (`renpy.sh <проект> test`, 13 testcase) по-прежнему можно
  прогнать только на машине с дисплеем — в контейнере SDL падает в segfault (см. docs/11).
* `zoya scared` — единственный Solid-плейсхолдер; в сценарии не используется.
